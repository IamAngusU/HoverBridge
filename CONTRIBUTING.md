# Contributing

Keep the geometric core independent of the DOM. New adapters should pass points, rectangles and monotonic time rather than reaching into browser globals from the core.

## Local checks

Node.js 20+ is required for development. Ready-built browser usage has no Node dependency.

```sh
npm install
npm exec -- playwright-core install chromium
npm run check
npm run bench
npm run size
```

The manifest pins top-level development versions. The original execution environment supplied TypeScript 5.8.3 and a preinstalled Playwright 1.57 beta runtime; the exact versions are recorded in `docs/testing.md`. No lockfile with invented registry integrity is supplied. Generate and review a lockfile during the first network-enabled clean dependency install before publishing a release.

Use an existing Chromium executable by setting `PLAYWRIGHT_EXECUTABLE_PATH`. Select `HOVERBRIDGE_BROWSER=firefox` or `webkit` after installing that engine. There is no claim that those engines have passed until their logs are recorded.

```sh
# POSIX example; use your actual installed browser path.
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

Windows PowerShell uses `$env:PLAYWRIGHT_EXECUTABLE_PATH = 'C:\path\to\chrome.exe'` before the command.

## Changes

Include a regression test that fails without the behavior change. Test deadline starvation, departure/re-entry, reversals, actual hit targets and teardown, not just polygon membership. Tests must not claim synthetic pen events are physical hardware testing or infer human error counts from internal samples.

`npm run demo:capture` captures the actual local demo and exercises its controls. On environments that prohibit browser navigation to files or loopback URLs, `HOVERBRIDGE_CAPTURE_MODE=fixture` explicitly selects original-asset fixture loading. The resulting report records the limitation rather than calling it a direct-navigation test.

Do not introduce runtime dependencies, network activity, global pointer-event locks or click-replay code without a documented reason. Avoid changing host attributes that are not owned by the adapter. Keep API, English/German README, defaults and versioned evidence consistent.

The standalone browser file is generated by a small static relative-module bundler. It does not evaluate source strings. Rebuild it from `src`, never edit `dist` directly.

## Reporting bugs

Include a minimal HTML reproduction, browser/OS, input device, expected/actual path and the relevant options. Screenshots of the debug corridor can help. Do not upload private application data, session tokens or unrelated logs. A failing test is better than a guessed diagnosis.
